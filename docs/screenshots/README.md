# Screenshots

Drop PNGs here and reference them from the main README.

Worth capturing, in this order — the first is the one people actually look at:

1. `feed.png` — the India feed in dark mode, wide enough to show the two-column
   layout (1400px or more). Include the month timeline and the category chips.
2. `reader.png` — an article open in the in-app reader, scrolled far enough to show
   the copyright hand-off card at the bottom.
3. `saved.png` — the Saved page with a collection, a note and a due date filled in.
4. `hindi.png` — any feed view with the language set to हिं, which shows off the
   bilingual work.

Take them with the window maximised, and crop out browser chrome and your bookmarks
bar. Once `feed.png` exists, add this line back under the Screenshots heading in the
main README:

    ![The India feed](docs/screenshots/feed.png)
